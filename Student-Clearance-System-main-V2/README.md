# OLOPSC Student Clearance System

This is a static, browser-only prototype. No server API, database, or account
registration is required. Serve the `Clearance-System-Architect(Web)` folder
with VS Code Live Server or run `python -m http.server 8000` from that folder,
then open `http://localhost:8000`.

Use the demo accounts in
[DEMO-CREDENTIALS.md](./Clearance-System-Architect%28Web%29/DEMO-CREDENTIALS.md).
The app stores demo session and clearance data in the current browser's local
storage. It is not suitable for real accounts or production use.
